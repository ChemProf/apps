🧪 Ionic Compounds

Type I: Metals with Fixed Charges

Group 1, 2, and metals like Al³⁺, Zn²⁺, Ag⁺ have fixed charges. Name: Metal + Nonmetal (change ending to -ide).

NaCl → Sodium chloride
CaBr₂ → Calcium bromide
Al₂O₃ → Aluminum oxide

Type II: Metals with Variable Charges

Transition metals often have multiple charges. Use Roman numerals in parentheses.

FeCl₂ → Iron(II) chloride (Fe²⁺)
FeCl₃ → Iron(III) chloride (Fe³⁺)
CuO → Copper(II) oxide (Cu²⁺)

Polyatomic Ions

Memorize common polyatomic ions. They keep their names in compounds. Watch for hydrogenated variants:

  • CO₃²⁻ → carbonate; HCO₃⁻ → hydrogen carbonate (or bicarbonate)
  • PO₄³⁻ → phosphate; HPO₄²⁻ → hydrogen phosphate; H₂PO₄⁻ → dihydrogen phosphate
  • SO₄²⁻ → sulfate; SO₃²⁻ → sulfite
NaHCO₃ → Sodium hydrogen carbonate
CaHPO₄ → Calcium hydrogen phosphate
KH₂PO₄ → Potassium dihydrogen phosphate

⚛️ Binary Molecular Compounds

Naming Rules

  • Use Greek prefixes to indicate atom counts (mono-, di-, tri-, tetra-, penta-, hexa-, hepta-, octa-, nona-, deca-)
  • Prefix on first element is dropped if there is only one atom
  • Second element always gets prefix and -ide ending
  • Element with lower electronegativity (more left/down in periodic table) is named first
CO → Carbon monoxide
CO₂ → Carbon dioxide
N₂O₄ → Dinitrogen tetroxide
PCl₅ → Phosphorus pentachloride

💧 Acids

Binary Acids (H + Nonmetal)

Use "hydro-" prefix and "-ic" suffix on the nonmetal root, followed by "acid".

HCl → Hydrochloric acid
H₂S → Hydrosulfuric acid
HBr → Hydrobromic acid

Oxyacids (H + Oxyanion)

If anion ends in -ate → acid ends in -ic. If anion ends in -ite → acid ends in -ous.

H₂SO₄ → Sulfuric acid (from sulfate)
H₂SO₃ → Sulfurous acid (from sulfite)
HNO₃ → Nitric acid
HNO₂ → Nitrous acid
